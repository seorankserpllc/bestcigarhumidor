# Best Cigar Humidor (bestcigarhumidor.com)

The premier interactive cigar storage selector, standalone review authority, and DIY build-vs-buy engineering platform for cigar aficionados.

## Overview

**Best Cigar Humidor** helps aficionados select the exact right preservation system for their collection, vitola formats, ambient climate, altitude, and budget.

### Core Features

- **Precision Humidor Selector**: 5-step diagnostic engine factoring in stick capacity, vitolas (Robusto, Churchill, Gordo), regional RH/temperature extremes, altitude hygrometric shifts, and maintenance preferences.
- **Standalone Product Reviews**: Individual programmatic review pages for top Amazon-verified humidors (electric wineadors, desktop Spanish cedar chests, travel cases, acrylic jars, and smart hygrometers) with detailed lab breakdown, pros/cons, specs, and FAQ Schema markup.
- **Build vs. Buy Calculator**: Direct financial, seal integrity, and labor comparison between turnkey retail humidors and DIY builds.
- **Engineering Blueprints**: Detailed step-by-step assembly blueprints (Tupperdor, Marine Coolidor, Converted Wineador, and Custom Spanish Cedar Cabinet) with exact parts lists and 2-way Boveda RH formulas.
- **Editorial Knowledgebase**: In-depth guides covering 14-day seasoning protocols, glass-top seal leak tests, mold vs. plume forensics, and high-altitude RH compensation.
- **Direct Amazon Affiliate Integration**: Compliant direct ASIN routing with dynamic tag management and Amazon Associates disclosures.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Typography**: Google Fonts (Cinzel + Plus Jakarta Sans)

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
